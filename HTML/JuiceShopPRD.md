# 🍹 Juice Shop App — Product Requirement Document (PRD)

## 🧭 Objective & Purpose

Create a mobile/web app for a local **Juice Shop** that allows users to browse the juice menu, place orders for delivery or pickup, and make digital payments easily.

---

## 📌 Scope

### In Scope:
- View juice items (with images, ingredients, prices)
- Add to cart & order placement
- Online payment (UPI/Card)
- Order tracking
- Admin dashboard to manage inventory & orders

### Out of Scope:
- Loyalty program
- Franchise support

---

## 🚀 Features & Requirements

### P1:
- Juice listing with filters (fruit type, size)
- Cart & checkout
- Order status updates
- Admin panel (CRUD for products)

### P2:
- Promo codes
- Reviews & ratings
- Daily deals

---

## 👥 User Stories

- 🧑‍🍳 As a **customer**, I want to **browse juices**, so I can find my favorite.
- 🧾 As a **user**, I want to **pay online**, so I avoid cash hassle.
- 🧑‍💼 As an **admin**, I want to **add/remove items**, so I can update the menu.

---

## ⚙️ Tech Stack

- Frontend: React Native / Flutter
- Backend: Node.js + MongoDB
- Payment: Razorpay / Stripe
- Hosting: Firebase / Vercel
