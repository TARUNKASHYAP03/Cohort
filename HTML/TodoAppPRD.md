# ✅ To-Do App — Product Requirement Document (PRD)

## 🧭 Objective & Purpose

Build a simple, fast, and responsive **To-Do List Application** that allows users to manage daily tasks efficiently. Users should be able to create, update, delete, and mark tasks as complete with minimal effort.

---

## 📌 Scope

### In Scope:
- User authentication (Sign Up / Login)
- Task creation, editing, and deletion
- Mark tasks as complete/incomplete
- Task categorization (tags or due dates)
- Responsive UI for mobile and desktop

### Out of Scope:
- Team collaboration features
- Sharing tasks or public boards
- Calendar integration (for this version)

---

## 🚀 Features & Requirements

### Priority 1 (P1)
- User Registration & Login (JWT based)
- Create, Read, Update, Delete (CRUD) tasks
- Toggle task completion status
- Assign due dates to tasks
- Basic categorization using tags

### Priority 2 (P2)
- Light/Dark mode toggle
- Task filtering & searching
- Sort by due date or status
- Offline support (PWA)
- Task notifications (basic reminders)

---

## 👥 User Stories

- 🧑‍💼 As a **new user**, I want to **register** so I can save my tasks.
- 🧑‍💻 As a **user**, I want to **create tasks with deadlines** so I stay on track.
- ✅ As a **user**, I want to **mark tasks as completed** to track progress.
- ✏️ As a **user**, I want to **edit or delete tasks** as needed.
- 🔍 As a **user**, I want to **filter and search tasks** quickly.

---

## ⚙️ Technical Requirements

- **Frontend:** React.js (with Tailwind CSS or Material UI)
- **Backend:** Node.js + Express.js
- **Database:** MongoDB (or PostgreSQL)
- **Authentication:** JSON Web Tokens (JWT)
- **API:** RESTful APIs
- **Hosting:** Vercel (Frontend), Render/Heroku (Backend)

---

## 🎨 Design Requirements

- Clean, modern, minimalistic interface
- Mobile-first responsive layout
- Color indicators for task status
- Consistent font and spacing (following design system)
- Figma mockups available with:
  - Task card layout
  - Add/edit task modal
  - Login/register UI
