# HTML Task Series - README

This README file documents a series of foundational HTML tasks designed to practice and understand core HTML concepts. Each task builds on key elements of front-end development using HTML.

---

## Task List

### **Task 1: Basic HTML Page**
- Create an HTML page with:
  - Title
  - `<h1>` Heading
  - `<p>` Paragraph
  - Meta tags for character encoding and viewport
  - A comment in the body section

### **Task 2: Page Structure and Styling**
- Add:
  - Main heading (`<h1>`)
  - Subheadings (`<h2>`, `<h3>`)
  - Paragraphs with bold, italic, and underlined text
  - Line break and horizontal rule
  - A disclaimer using `<small>`

### **Task 3: Lists and Descriptions**
- Unordered list of favorite foods
- Ordered list of morning tasks
- Nested list of beverages (hot and cold)
- Description list with 3 programming terms and meanings

### **Task 4: Links and Navigation**
- Link to external website and internal section
- Navigation menu with Home, Services, and Contact
- External link that opens in a new tab (using `rel="noopener"`)
- Downloadable link
- Email link using `mailto:`

### **Task 5: Images**
- Image with:
  - Width = 400px
  - Alt text and title
- Clickable image linking to external site
- Background image in a `<div>` that covers and centers

### **Task 6: Tables**
- Table with 3 columns: City, Country, Population
- Table with caption showing favorite foods and categories
- Complex table layout for a weekly schedule using `rowspan` and `colspan`

### **Task 7: Forms and Inputs**
- Form with:
  - Number field
  - Password field with validation (min 8 chars using `pattern`)
  - Textarea
  - Phone number field (accepts only numbers)
- Styled and centered using CSS

### **Task 8: Semantic Layout**
- Page structure using:
  - `<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<aside>`, `<footer>`
- Use of `aria-label` for accessible navigation
- Semantic blog layout

### **Task 9: Media and Multimedia**
- Embed video with:
  - `controls`, `autoplay`, `poster`
  - Subtitles via `<track>`
- Audio player with multiple formats
- Embedded YouTube video using `<iframe>`
- Table listing common video/audio formats

### **Task 10: Attributes and Custom Data**
- Paragraph with `id` and `class`
- Anchor with `title` and `target`
- Input with `required` and `placeholder`
- Styled paragraph using `style` or CSS class
- Use of `data-` attribute for custom metadata

### **Task 11: Forms, Video, and Canvas**
- Form with:
  - Email (required)
  - Date picker for DOB
  - Color picker
- Embedded video with `poster`, `controls`, subtitles
- Rectangle using `<canvas>` and JavaScript

### **Task 12: PRD-Based HTML Website**
- Build a content-based product website using only HTML as per PRD
- Include logical structure, meaningful sections, and navigation
- Estimate time required for PRD planning and development

---

## Notes
- All styling should be done via external CSS for maintainability.
- Use semantic HTML for better accessibility and SEO.
- Use proper attributes (`rel="noopener"`, `aria-label`) to enhance security and usability.
