# 💇‍♀️ Salon Booking App — Product Requirement Document (PRD)

## 🧭 Objective & Purpose

Design an app that lets users book appointments at a salon for different services, choose time slots, and manage their bookings.

---

## 📌 Scope

### In Scope:
- Browse services with pricing
- Appointment booking
- Service provider selection
- Time slot availability
- Payment integration

### Out of Scope:
- On-demand home service
- Staff management system

---

## 🚀 Features

### P1:
- Book salon service with stylist & slot
- View past/future bookings
- Payment gateway integration

### P2:
- Add to calendar
- Apply discount codes
- Rate stylist/service

---

## 👥 User Stories

- 💇 As a **user**, I want to **book an appointment**, so I don’t wait at the salon.
- 🧑‍🎤 As a **stylist**, I want to **see my schedule**, so I manage my clients.

---

## ⚙️ Tech Stack

- Frontend: Flutter / React Native
- Backend: Django REST / Node.js
- DB: Firebase Firestore / PostgreSQL
- Auth: Firebase Auth
